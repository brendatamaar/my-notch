Built for the agent era

Your agents ask. The notch answers.

Long-running agents stop to ask permission, then wait. MyNotch surfaces that moment at the top of your screen, wherever you're working.

  • Approve from the notch. Claude Code permission requests wait for your decision, or fall back to the terminal prompt.
  • Any agent, one endpoint. POST running, awaiting_approval, done or error from anything that can make an HTTP request.
  • Hooks in one click. Settings → Copy Claude Code hooks, merge, restart.
PowerShell
# MyNotch listens on 127.0.0.1:9999
$payload = @{
    agent   = 'my-agent'
    status  = 'done'
    message = 'Build finished'
    session = 'demo'
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri 'http://127.0.0.1:9999/agent' `
  -ContentType 'application/json' -Body $payload

Local-first

It lives on your PC. Not in a cloud.

No account, no telemetry dashboard, no sign-in. Here is exactly what touches the network.

Your data, your folder

Settings, tasks and saved commands live in %LOCALAPPDATA%\MyNotch. Clipboard history and notification contents stay in memory only.

Loopback only

The agent listener binds to 127.0.0.1:9999 and rejects any request that carries a browser Origin header.

Honest about requests

Lyrics lookup sends track metadata to LRCLIB. Prayer times use Aladhan. A calendar feed is fetched from the URL you configure. Missing integrations show as unavailable, never as made-up data.

Get it

Build it in a minute.

There's no installer yet, so MyNotch is built from source. It takes the .NET 8 SDK and a single script.

Clone the repository

git clone https://github.com/brendatamaar/my-notch.git cd my-notch

Build

From the repo root, in PowerShell.

.\build.ps1

Run

Hover the notch at the top of your screen. A tray icon holds Settings.

& .\MyNotch\bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\MyNotch.exe

Requirements

  • OSWindows 10 (1809) or newer, x64
  • SDK.NET 8 SDK
  • ToolingVisual Studio 2022 or Build Tools with the Windows SDK / Appx tasks
  • OptionsDocker, Git and gh unlock the matching dev features
Heads up: use a regular Debug or Release build. Native AOT publishing currently compiles but the executable fails at WinUI startup.
